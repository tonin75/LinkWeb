# 链接导航网页

一个现代化的链接导航网页，支持分类管理、后台管理和本地数据存储。

## 功能特点

- 🎨 **现代化界面**：深色主题设计，响应式布局，适配不同屏幕尺寸
- 📁 **分类管理**：支持按分类筛选和展示链接
- 🔧 **后台管理**：添加、编辑、删除链接，方便维护
- 💾 **本地存储**：数据存储在浏览器localStorage中，刷新页面不丢失
- 🎯 **链接卡片**：每个链接都有图标、描述和访问按钮
- 🚀 **快速加载**：使用React和Vite构建，性能优异

## 技术栈

- React 18
- React Router v6
- Vite 5
- CSS3 (响应式设计)
- localStorage (数据持久化)

## 安装和运行

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

应用将在 `http://localhost:5173/` 运行

### 3. 构建生产版本

```bash
npm run build
```

构建后的文件将在 `dist` 目录中

## 使用方法

### 浏览链接

1. 打开应用首页，默认显示所有链接
2. 在左侧导航栏选择分类，右侧会显示对应分类的链接
3. 点击链接卡片上的"访问链接"按钮，会在新标签页打开链接

### 后台管理

1. 在左侧导航栏点击"后台管理"进入管理页面
2. **添加新链接**：
   - 填写链接标题、URL、描述、图标、分类和颜色
   - 点击"添加链接"按钮
3. **编辑链接**：
   - 在链接列表中找到要编辑的链接
   - 点击"编辑"按钮
   - 修改表单中的信息
   - 点击"更新链接"按钮
4. **删除链接**：
   - 在链接列表中找到要删除的链接
   - 点击"删除"按钮
   - 确认删除操作

## 数据管理

- 所有数据存储在浏览器的localStorage中
- 数据格式：
  - `categories`：分类数组
  - `links`：链接数组
- 清空浏览器数据会导致链接数据丢失
- 建议定期备份重要链接

## 自定义配置

### 修改初始数据

编辑 `src/App.jsx` 文件中的 `initialCategories` 和 `initialLinks` 数组，可修改默认分类和链接。

### 修改样式

编辑 `src/index.css` 文件，可自定义应用的样式，包括颜色、布局等。

## 注意事项

- 本应用仅在客户端运行，数据存储在浏览器本地

- 适合个人使用或小团队内部使用
